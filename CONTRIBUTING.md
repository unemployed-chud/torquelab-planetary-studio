# Contributing to TorqueLab

Thanks for helping make engineering education more interactive!

1. Open an issue to discuss significant changes before building them.
2. Fork the repository and work in a focused feature branch.
3. Preserve the standard planetary kinematic identities and 3-planet assembly condition.
4. Add tests to `tests/physics.test.mjs` for mathematical changes; run `npm test`.
5. Verify layout on desktop and mobile. Use keyboard controls where possible.
6. Submit a pull request with a clear description, screenshots for UI changes, and test results.

Inaccurate physical claims and unsafe manufacturing advice will not be accepted. The illustrated tooth profiles remain schematic.
